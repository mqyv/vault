Six plugins que tu ne trouveras pas ailleurs

Vault reprend tout le catalogue d'Equicord et de Vencord, ainsi que les thèmes, la sauvegarde cloud et les mises à jour automatiques. Ces six-là sont écrits pour Vault.

  1. BulkSend

    Un bouton dans la barre de chat : une ligne par message, envoyés dans l'ordre avec un délai réglable en millisecondes.

  2. ClearMessages

    Supprime tes propres messages, du plus récent au plus ancien, dans un MP entier ou à partir d'un message précis.

  3. CopyProfile

    Copie l'avatar, la bannière, la bio et les pronoms d'un utilisateur sur ton propre compte, après confirmation.

  4. FakeVoice

    Apparais muet ou sourd pour les autres tout en continuant à parler et à entendre. Clic gauche pour le micro, clic droit pour le casque. Expérimental.

  5. BetterMicrophone

    Débloque un débit d'encodage plus élevé pour le micro. Expérimental : une mise à jour de Discord peut le casser.

  6. VaultPerformance

    Désactive les animations, les transitions et les flous coûteux pour alléger Discord. Activé par défaut.

Installer Vault en trois étapes

Pas de compte à créer. L'installeur ajoute Git et Node.js s'il en manque, télécharge Vault et le compile : compte quelques minutes.

Télécharge VaultSetup.exeLe fichier fait environ 2 Mo.
Lance-leClique sur Suivant, puis Installer. Discord sera fermé pendant l'installation.
Rouvre DiscordVault apparaît dans les Réglages, onglet « Vault ».

Recommandé. Windows peut afficher « Windows a protégé votre PC » car l'installeur n'est pas signé : Informations complémentaires → Exécuter quand même.

Télécharger VaultSetup.exe

Une seule commande, dans PowerShell.

irm https://raw.githubusercontent.com/mqyv/vault/main/scripts/install-vault.ps1 | iex

Prérequis : Git et Node.js LTS. Ferme Discord avant d'injecter.

npm i -g pnpm
git clone https://github.com/mqyv/vault.git Vault
cd Vault
pnpm install
pnpm build
pnpm inject

Questions fréquentes

Est-ce que Vault est gratuit ?

Oui. Vault est un logiciel libre sous licence GPL-3.0 : tu peux lire, modifier et redistribuer le code.

Comment fonctionnent les mises à jour ?

Au lancement, Vault récupère les derniers correctifs et affiche une notification « Restart ». Un clic et tu es à jour.

Comment désinstaller Vault ?

Via « Ajout/Suppression de programmes » si tu as utilisé l'installeur, ou avec la commande pnpm uninject pour une installation manuelle.

Y a-t-il un risque pour mon compte Discord ?

Modifier le client Discord enfreint ses conditions d'utilisation. Aucun bannissement n'est connu pour l'usage d'un client mod, mais si ton compte est essentiel, évite tout client mod.

Sur quels systèmes Vault fonctionne-t-il ?

L'installeur graphique est prévu pour Windows 10 et 11. Le build manuel fonctionne ailleurs avec Node.js et pnpm.
