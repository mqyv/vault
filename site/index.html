Six plugins que Discord ne vous donne pas.

Vault est un mod pour Discord sur ordinateur. Il envoie vos messages en rafale, efface les vôtres d'un coup, copie un profil et vous affiche muet sans couper le micro. Il embarque aussi plus de 370 plugins d'Equicord et Vencord, et se met à jour tout seul.

Écrits pour Vault, absents partout ailleurs

Ni Equicord ni Vencord ne les proposent. Ils vont plus loin que ce que Discord autorise d'habitude : à vous de vous en servir avec discernement.

  1. BulkSend

    Collez une liste, une ligne par message : tout part dans l'ordre, avec le délai que vous choisissez, en millisecondes.

  2. ClearMessages

    Efface vos propres messages d'un MP ou d'un salon, en entier ou à partir d'un message précis, du plus récent au plus ancien.

  3. CopyProfile

    Reprend l'avatar, la bannière, la bio et les pronoms d'un autre compte et les applique au vôtre, après confirmation.

  4. FakeVoice

    Les autres vous voient muet ou sourd pendant que vous continuez à parler et à écouter. Clic gauche pour le micro, clic droit pour le casque.Expérimental.

  5. BetterMicrophone

    Encode votre voix jusqu'à 510 kbit/s en stéréo, au lieu des 64 kbit/s de Discord, avec un gain réglable jusqu'à +12 dB.Expérimental : une mise à jour de Discord peut le casser.

  6. VaultPerformance

    Coupe les animations, les transitions et les flous coûteux pour alléger Discord. Activé par défaut.

Installer Vault en trois étapes

Aucun compte à créer. L'installeur ajoute Git et Node.js s'ils manquent, télécharge Vault et le compile : comptez quelques minutes.

Lancez l'installeurVaultSetup.exe sur Windows (environ 2 Mo), ou la commande de l'onglet macOS sur Mac.
Laissez-le travaillerIl ferme Discord, ajoute ce qui manque, télécharge Vault et le compile.
Rouvrez DiscordVault apparaît dans les Réglages, onglet « Vault ».

Si quelque chose bloque

« Windows a protégé votre PC »
L'installeur n'est pas signé. Cliquez sur Informations complémentaires, puis Exécuter quand même.
L'installation échoue
Le journal complet est dans %TEMP%\vault-install.log (Windows) ou $TMPDIR/vault-install.log (Mac). Joignez-le à un signalement sur GitHub.
Revenir à Discord sans Vault
Désinstallez depuis « Ajout/Suppression de programmes » sur Windows, ou avec la commande de l'onglet macOS suivie de --uninstall.

Recommandé sur Windows 10 et 11. Windows peut afficher « Windows a protégé votre PC », car l'installeur n'est pas signé : Informations complémentaires, puis Exécuter quand même.

Télécharger VaultSetup.exe

La même installation en une commande, à coller dans PowerShell.

irm https://raw.githubusercontent.com/mqyv/vault/main/scripts/install-vault.ps1 | iex

Collez cette commande dans le Terminal (Applications, puis Utilitaires). Elle ne demande pas de mot de passe. Si macOS refuse de modifier Discord, autorisez Terminal dans Réglages Système, Confidentialité et sécurité, Gestion des apps.

curl -fsSL https://raw.githubusercontent.com/mqyv/vault/main/scripts/install-vault.sh | bash

Prérequis : Git et Node.js 22 ou plus. Fermez Discord avant la dernière commande, qui installe Vault dans Discord.

npm i -g pnpm
git clone https://github.com/mqyv/vault.git Vault
cd Vault
pnpm install
pnpm build
pnpm inject

À savoir : modifier le client Discord enfreint ses conditions d'utilisation. Aucun bannissement n'est connu pour l'usage d'un client mod, mais n'utilisez pas Vault sur un compte que vous ne pouvez pas vous permettre de perdre.

Questions fréquentes

Est-ce que Vault est gratuit ?

Oui. Vault est un logiciel libre sous licence GPL-3.0 : vous pouvez lire, modifier et redistribuer le code.

Comment fonctionnent les mises à jour ?

Au lancement de Discord, Vault récupère les derniers correctifs et affiche une notification « Restart ». Un clic suffit pour redémarrer à jour.

Comment désinstaller Vault ?

Sur Windows, depuis « Ajout/Suppression de programmes ». Sur Mac, en relançant la commande d'installation suivie de --uninstall.

Y a-t-il un risque pour mon compte Discord ?

Modifier le client Discord enfreint ses conditions d'utilisation. Aucun bannissement n'est connu pour l'usage d'un client mod, mais n'utilisez pas Vault sur un compte que vous ne pouvez pas vous permettre de perdre.

Vault marche-t-il sur téléphone ?

Non. Vault s'installe sur le Discord de bureau, sous Windows 10 et 11 ou macOS. Sur votre téléphone, Discord reste celui d'origine.
