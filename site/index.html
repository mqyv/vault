Installation

Prêt en trente secondes.

Aucun compte, aucune configuration. L'installeur s'occupe de tout.

Télécharge l'installeurVaultSetup.exe, environ quelques Mo.
Lance-leSuivant → Installer. Discord peut rester fermé.
Rouvre DiscordVault apparaît dans tes Réglages.

Recommandé. Windows peut afficher « Windows a protégé votre PC » car l'installeur n'est pas signé : Informations complémentaires → Exécuter quand même.

Télécharger VaultSetup.exe

Une seule commande, dans PowerShell.

irm https://raw.githubusercontent.com/mqyv/vault/main/scripts/install-vault.ps1 | iex

Prérequis : Git et Node.js LTS. Ferme Discord avant d'injecter.

npm i -g pnpm
git clone https://github.com/mqyv/vault.git Vault
cd Vault
pnpm install
pnpm build
pnpm inject
FAQ

Questions fréquentes

Est-ce que Vault est gratuit ?

Oui, entièrement. Vault est un logiciel libre sous licence GPL-3.0 : tu peux lire, modifier et redistribuer le code.

Comment fonctionnent les mises à jour ?

Au lancement, Vault récupère les derniers correctifs et affiche une notification « Restart ». Un clic et tu es à jour.

Comment désinstaller ?

Via « Ajout/Suppression de programmes » si tu as utilisé l'installeur, ou avec la commande pnpm uninject pour une installation manuelle.

Y a-t-il un risque pour mon compte ?

Modifier le client Discord enfreint ses conditions d'utilisation. Dans les faits, aucun bannissement n'est connu pour l'usage d'un client mod, mais si ton compte est essentiel, évite tout client mod.

Sur quels systèmes ça marche ?

L'installeur graphique est prévu pour Windows 10 et 11. Le build manuel fonctionne ailleurs avec Node.js et pnpm.
